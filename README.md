# SmartFlow ERP

Plataforma inteligente de facturación, gestión de pedidos e inventario para PYMES, con aplicación web y móvil.

Proyecto de Ingeniería de Software I, CEUTEC.
Autora: Maria Cristina Lopez

## Funciones principales

- Gestión de clientes y productos
- Control de inventario con descuento automático
- Gestión de pedidos con estados
- Generación de facturas en PDF con impuestos
- Reportes y dashboard
- Roles y permisos (personal y portal del cliente)
- Notificaciones

## Stack tecnológico

| Capa | Tecnología |
|---|---|
| Frontend web | React |
| App móvil | React Native |
| Backend | Node.js + Express (API REST) |
| Base de datos y autenticación | Supabase (PostgreSQL + Auth) |
| Control de versiones | Git y GitHub |
| Gestión del proyecto | Trello (Kanban) |
| Asistente de desarrollo con IA | Claude |
